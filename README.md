# vprwre.com

The website for **The Take by VPRWRE**. Every story first ran as a carousel on [@vprwre](https://www.instagram.com/vprwre/).

- Static site served by GitHub Pages from the repository root (custom domain in `CNAME`).
- `posts.json` lists every published story.
- `tools/` holds the generator (`build.py`), the stylesheet source and the background research.
- Fonts: Archivo and Newsreader, self-hosted under the SIL Open Font License (`assets/fonts`).
